Hello! Thanks for checking out my 99% offline WARDOGS mortar/artillery calculator port! 

--*Please note that this calculator takes up ~3.17gb of space on a storage drive.*

--*Zestafona and color map options, only work if you have internet connection and the original browser based calculator is working*

----------------*HOW TO*----------------
1. To install the application, simply download the Setup Installer "WARDOGS Artillery Calculator Setup (offline v4).exe" and run it.
2. This will prompt you with an installer and simply choose where you want to install to.
3. After installation, navigate to the "...\WARDOGS Artillery Calculator - Offline" folder that has the "WARDOGS Artillery Calculator.exe" and double click to run.
4. (2) Things may occur: 
    1. A transparent windows will popup that says "...Not Responding." -> Simply let it run and it will open a blank calculator window -> Re-open application and *Ta-da*
    2. It'll just work.
5. Delete Setup.exe after installtion.
